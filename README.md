# Upnex It

আমার একটি সফটওয়্যার সার্ভিস কোম্পানি আছে যেখানে আমি কাস্টম সফটওয়্যার অর্থাৎ স্কুল ম্যানেজমেন্ট, হসপিটাল ম্যানেজমেন্ট সফটওয়্যার সার্ভিস দিয়ে থাকি। তো এর জন্যে আমার একটি কোম্পানির ওয়েবসাইট প্রয়োজন যেটি হবে প্রফেশনাল, বাংলা, ইংলিশ সাপোর্ট। তো তুমি একটু Google analysis করো এবং একটি প্রফেশনাল আমার কোম্পানির জন্যে একটি ওয়েবসাইট তৈরি করো যেটি fully functional এবং প্রফেশনাল।
